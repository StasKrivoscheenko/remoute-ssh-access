# Remoute SSH Access

Приложение для управления серверами по SSH и SFTP. При запуске открывается адресная книга, после подключения — рабочее окно в тёмном стиле с фиолетовыми акцентами.

## Возможности

- Адресная книга с недавними и закреплёнными подключениями.
- Вход по SSH-ключу, SSH-агенту или паролю. Пароли и парольные фразы не сохраняются.
- Сводка состояния сервера, файловый менеджер SFTP с предпросмотром текстовых файлов, управление службами и просмотр журналов.
- Интерактивный терминал с PTY и отдельная вкладка для разовых команд.
- Локальные SSH-туннели, просмотр процессов и управление Docker-контейнерами.

## Готовая версия для Windows

Запустите `release/Remoute SSH Access.exe`. Python и отдельная установка библиотек на целевом компьютере не нужны. Сборка предназначена для 64-разрядной Windows. Адресная книга хранится в профиле пользователя Windows на каждом компьютере отдельно.

## Требования

- Windows 10/11 и Python 3.10 или новее.
- Учётная запись SSH на сервере. На сервере должен быть включён SFTP.
- Ключ хоста сервера должен быть проверен и записан в `known_hosts`.

## Установка и запуск

Откройте PowerShell в папке программы и выполните:

```powershell
py -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
pip install -r requirements.txt
python main.py
```

Если PowerShell запрещает активацию окружения, используйте Python из него напрямую:

```powershell
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe main.py
```

## Подключение и ключи

В форме подключения выберите один из режимов:

- **Автоматически** — приложение проверит SSH-агент и ключи, а при отказе запросит пароль учётной записи.
- **Только пароль** — вход по паролю без попытки использовать ключи.
- **Только ключ/агент** — вход только с помощью ключа или SSH-агента.

По умолчанию проверяются `~/.ssh/id_ed25519`, `id_ecdsa` и `id_rsa`. Можно выбрать другой приватный ключ. Для зашифрованного ключа приложение запросит парольную фразу. Пароль и парольная фраза применяются только при текущем входе и не записываются в адресную книгу.

Приложение отклоняет неизвестные ключи серверов. Если сервер ещё не добавлен в `known_hosts`, подключитесь к нему один раз через OpenSSH, проверьте отпечаток ключа и повторите вход. Существующая запись `Host linux-vm` в `%USERPROFILE%\.ssh\config` импортируется в адресную книгу.

## Терминал и дополнительные инструменты

Для интерактивного терминала используется удалённая PTY-оболочка `xterm-256color` и пакет `pyte`, который устанавливается командой `pip install -r requirements.txt`. Поддерживаются ввод команд, изменение размера экрана, вставка из буфера обмена, `Ctrl+C` для прерывания и копирование выделенного через `Ctrl+Shift+C` или кнопку. Мышиные события терминальным программам не пересылаются. Разовые SSH-команды находятся в отдельной вкладке.

Локальный туннель слушает только `127.0.0.1` на этом компьютере. Например, перенаправьте локальный порт `15432` на `127.0.0.1:5432` на стороне сервера и подключите локальный клиент к `127.0.0.1:15432`.

Вкладка **Docker** позволяет запускать, останавливать и перезапускать контейнеры, смотреть сведения, последние журналы и статистику ресурсов, запускать команду внутри контейнера и копировать его ID. Удаление контейнера требует подтверждения. Вкладка **Процессы** показывает процессы с наибольшей загрузкой CPU и отправляет выбранному процессу сигнал SIGTERM.

## Ограничения

- Команды, требующие `sudo` или интерактивного пароля, могут не сработать из вкладок служб и разовых команд.
- Удалить можно только пустую удалённую папку. Удаление файлов и контейнеров требует подтверждения.
- Параметры OpenSSH вроде некоторых вариантов `ProxyCommand` могут не поддерживаться Paramiko.
- Перед остановкой служб и удалением контейнеров убедитесь, что это безопасно для сервера.
